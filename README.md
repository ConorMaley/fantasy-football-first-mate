# Fantasy Football First Mate
Combine all your fantasy football leagues into one app. Live data, league history, and friends included!

## Sample user journey
- User signs up
- User adds active ESPN league 1234 to account
- User adds active Yahoo league 99999 to account
- Leagues are synced to user's account
- User's main dashboard includes snapshots of each active league. Leagues can be opened to view more details about the league - Standings, matchups by week, potential pickups. Not necessary that the user makes roster moves, but a link is provided for the user to go to the platform and make changes to their team.
- User adds last year's ESPN league.
    - Historical data updated. If any other users are on first mate, you can connect them with a your user.
- User maps friend from ESPN league and Yahoo league
- User can view list of friends - their all time records, championships won, playoffs made, active leagues.
- User can send invite to friend to sign up, after sign up, they can automatically access any links to leagues they have already been added to.
- User can view all time record against friends.
- User can group past leagues' from different years to record matchups, standings, transactions over the years across different platforms (ESPN, Yahoo, Sleeper, etc.)
